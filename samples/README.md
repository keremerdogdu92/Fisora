# Samples

Bu klasor sadece anonimlestirilmis veya sentetik test verisi icindir.

## Kurallar

- Gercek musteri verisi anonimlestirilmeden eklenmez.
- VKN/TCKN, IBAN, belge numarasi ve unvanlar sentetik olmalidir.
- Test dosyalari Faz 0 prototiplerini calistirmaya yetecek kadar kucuk
  tutulmalidir.
- Zirve'den gelen gercek format ornegi eklenecekse once hassas alanlar
  temizlenmelidir.

## Mevcut Dosyalar

- `chart_accounts/`: 3 sentetik hesap plani varyasyonu
- `invoices/`: Alis, satis ve karisik KDV JSON ornekleri
- `bank/`: Sentetik banka ekstresi CSV ornegi
